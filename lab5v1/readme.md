### Тема
Індексатори та перевантаження операторів.
Середовище розробки.

Варіант
1. Клас IntArray (Масив цілих чисел)
- Поле: _data
- Властивість: Length
- Індексатор: this[int index]
- Перевантажені оператори: +, ==, !=
- Перевизначені методи: ToString(), Equals(), GetHashCode()
